## 1. Как узнать результат без запуска

В прошлом уроке мы описали порядок сложения двух чисел. Теперь попробуем проследить короткую запись на Python: какие действия она задаёт и что должно получиться после каждого шага.

Для этого не нужно заранее уметь программировать. Будем разбирать только те элементы, которые объяснены в уроке. Вам также не нужно устанавливать Python или выполнять строки на своём устройстве.

В уроке 5.5 мы уже различали исходный код и его выполнение. Исходный код — текст программы на языке программирования. Само появление такого текста на странице ещё не означает, что компьютер его выполнил.

**Прослеживание выполнения — разбор по правилам: какая инструкция идёт следующей, какие значения получены и что изменилось.** Здесь мы будем делать такой разбор вручную и предсказывать вывод.

Это похоже на остановки в истории заметки из модуля 8: на выбранном моменте нельзя учитывать будущий ответ как уже полученный. Но теперь рассматриваем простую последовательность одной программы, без сети, других участников и сохранения данных.

После урока вы сможете объяснить небольшой фрагмент и составить таблицу его выполнения. Сначала разберём одно вычисление, затем показ, затем несколько строк по порядку.

**Проверьте себя.** Вы прочитали код и рассчитали ожидаемый результат на бумаге. Это доказывает, что программа была запущена на вашем компьютере?

**Ответ:** нет. Вы выполнили ручной разбор по правилам. Для фактического выполнения нужны соответствующие программные средства; в задании запуска не требуется.

## 2. Что означает выражение

Начнём с чисел 2 и 3. В наших примерах это обычные числовые данные. Знак `+` задаёт сложение.

**Выражение — запись, по которой получается значение.** Например:

```python
2 + 3
```

Здесь два числа и действие сложения. Значение этого выражения — число 5.

| Элемент | Что означает |
|---|---|
| `2` | Первое числовое значение |
| `+` | Действие сложения |
| `3` | Второе числовое значение |
| Пробелы вокруг `+` | Помогают читать запись; сами не прибавляют ничего к числам |

Запись `2 + 3` и её значение 5 — разные вещи. По записи мы получаем значение, но это ещё не отдельное указание показать его человеку.

В некоторых средствах работы с Python вычисленные значения могут показываться автоматически. Наши примеры здесь разбираются как последовательность инструкций исходного текста, без такого дополнительного показа. Чтобы явно задать вывод, будем использовать отдельное средство.

**Проверьте себя.** В выражении `2 + 3` знак `+` является частью полученного числа 5?

**Ответ:** нет. Знак задаёт действие. Полученное значение — число 5, а `2 + 3` — запись, по которой оно вычислено.

## 3. Как задать показ результата

**Вывод — данные или сообщения, которые программа выдаёт при работе.** В наших примерах вывод будет показан как текст с числами.

Для явной выдачи используем встроенное средство Python с именем `print`. Это имя записывается латинскими буквами именно так. Сейчас достаточно знать его действие; общее понятие функции разберём позже, в уроке 9.6.

После `print` стоят круглые скобки. Они выделяют то, что передаётся для выдачи. Если внутри записано выражение, сначала получается его значение, затем `print` выдаёт это значение. В обычном показе нашего примера оно появляется на отдельной строке.

Теперь все элементы следующей записи объяснены:

```python
print(2 + 3)
```

| Элемент | Роль |
|---|---|
| `print` | Выдать значение для показа |
| Открывающая `(` и закрывающая `)` | Ограничить переданное выражение |
| `2 + 3` внутри скобок | Получить значение сложения |

Порядок действий такой:

```text
Вычислить 2 + 3 → получить 5 → выдать для показа 5
```

Ожидаемый вывод:

```text
5
```

В этом блоке показан только вывод. Слово `print`, скобки и знак сложения в него не входят: выводить исходную строку как текст мы не задавали.

**Проверьте себя.** Для `print(2 + 3)` назовите сначала вычисленное значение, затем ожидаемую строку вывода.

**Ответ:** Выражение даёт 5, затем `print` показывает 5. Исходная строка целиком не печатается. При затруднении разделите вычисление и показ.

## 4. Что произойдёт со второй строкой

Добавим ещё одну строку с уже знакомым сложением:

```python
print(2 + 3)
print(1 + 1)
```

В этой простой последовательности сначала выполняется первая строка, потом вторая. Условий, повторений и переходов здесь нет.

Первая строка вычисляет 5 и показывает его. Вторая вычисляет 2 и показывает его на следующей строке. Второй показ не стирает первый в истории вывода нашего примера.

Ожидаемый вывод целиком:

```text
5
2
```

Это два показанных значения в определённом порядке. Число 2 не заменяет число 5 и не прибавляется к нему: такое действие в записи отсутствует.

Не будем переносить правило «сверху вниз» на любую программу без оговорок. Когда появятся условия, циклы и функции, они будут влиять на то, какая инструкция выполняется следующей. Пока у нас только обычная последовательность.

**Проверьте себя.** Вторая строка автоматически удаляет результат первой и оставляет только 2?

**Ответ:** нет. В нашем примере вывод содержит сначала 5, затем 2. Очистка или замена прежнего вывода не задана.

## 5. Как остановиться после каждого шага

**Состояние на шаге — существенные для задачи данные в выбранный момент.** Сейчас будем следить за очередной строкой, её вычисленным значением и всем уже выданным выводом.

Не нужно пытаться изобразить всю память компьютера. Таблица помогает ответить на конкретные вопросы: «Какую строку разобрали? Что вычислилось? Что уже показано?»

Для предыдущего примера получится:

| Момент | Вычисление текущей строки | Полученное значение | Весь вывод к этому моменту |
|---|---|---|---|
| До первой строки | Ещё не выполнялось | — | Пусто |
| После первой строки | 2 + 3 | 5 | 5 |
| После второй строки | 1 + 1 | 2 | Сначала 5, затем 2 |

«Сначала» и «затем» в таблице поясняют порядок. Программа не печатает эти слова. В настоящем блоке ожидаемого вывода выше каждое число занимает свою строку.

До второй строки нельзя включать её результат в уже состоявшийся вывод. Мы можем заранее предсказать, что будет дальше, но это не меняет состояния в выбранной точке.

Есть ещё более точная остановка: после вычисления 5, но перед выдачей его через `print`. В этот момент значение уже получено, а вывод ещё пуст. В таблице мы выбрали более крупные остановки — после целых строк, каждая из которых включает и вычисление, и показ.

**Проверьте себя.** В разборе мы остановились после первой строки, которая показывает 5. Вторая строка должна показать 2, но ещё не выполнялась. Запишите весь вывод в точке остановки.

**Ответ:** Пока в выводе только 5. Число 2 относится к ожидаемому продолжению. Если добавили его раньше времени, ещё раз отметьте момент остановки.

## 6. Как добавить другое действие

Кроме сложения нам понадобится умножение. В записи Python его обозначает знак `*`, который выглядит как звёздочка.

Например, выражение `4 * 2` означает умножить 4 на 2. Получается 8. Это не буква «икс» и не знак сноски.

После разбора знака можно заменить вторую строку:

```python
print(2 + 3)
print(4 * 2)
```

Первая строка даёт прежнее 5. Вторая даёт 8.

| После строки | Что вычислено в ней | Весь вывод |
|---|---|---|
| Первой | 2 + 3 даёт 5 | 5 |
| Второй | 4 * 2 даёт 8 | Сначала 5, затем 8 |

Ожидаемый вывод:

```text
5
8
```

Не нужно складывать результаты двух строк. Второй `print` показывает своё вычисленное значение, а не общую сумму всего, что когда-либо было показано.

Мы используем только одно арифметическое действие внутри каждого `print`. Приоритет нескольких разных операций сейчас не требуется.

**Проверьте себя.** В записи `4 * 2` звёздочка обозначает обычный символ, который нужно показать рядом с числами?

**Ответ:** нет. В этом выражении она задаёт умножение. Вычисляется 8; при передаче выражения в `print` показывается именно это значение.

## 7. Что изменится, если поменять строки местами

Предыдущий пример показывал 5, затем 8. Теперь рассмотрим отдельный вариант с начала:

```python
print(4 * 2)
print(2 + 3)
```

В нём те же два выражения, но первой стоит строка с умножением.

```text
8
5
```

Изменился порядок вывода. Нельзя считать результат полностью одинаковым только потому, что в обоих случаях встречаются числа 5 и 8.

Здесь вычисления независимы: ни одна строка не использует результат другой. Поэтому их значения после перестановки не изменились, хотя последовательность показа стала другой.

В уроке 9.1 два независимых чтения можно было переставить до сложения. Здесь тоже полезно спросить, что от чего зависит. Но дополнительно нужно учитывать требуемый порядок вывода. Если по задаче сначала должна показываться сумма, вариант с умножением первым уже не соответствует этому требованию.

**Проверьте себя.** В одном варианте показаны 5 и 8, в другом — те же числа в обратном порядке. Запишите оба вывода так, чтобы различие было видно.

**Ответ:** Первый вывод: 5, затем 8; второй: 8, затем 5. Последовательность — часть результата. Простого перечисления двух чисел без порядка недостаточно.

## 8. Что можно заключить по показанным числам

Наш фрагмент задаёт вычисления и показ. В нём нет действий с файлами, обращений к «Полке» или записи в базу данных.

Поэтому показ числа не подтверждает его долговременное сохранение. Как и в предыдущих модулях, рабочее значение, видимый результат и сохранённая запись — разные вещи.

Есть ещё один вопрос: получилось ли то, что требовалось человеку? Допустим, задача звучала так: «Сначала покажите сумму 2 и 3, затем произведение 4 и 2». Первый вариант подходит. Переставленный вариант выводит правильные арифметические значения, но нарушает ожидаемый порядок.

В уроке 5.5 мы уже видели: запись может быть допустимой, но задавать не то действие, которое было нужно. **Синтаксис — правила допустимого построения записи на языке.** Соблюдение этих правил само по себе не доказывает соответствие задаче.

Чтобы проверить небольшой пример, удобно последовательно выяснить: какие данные заданы, какие действия указаны, что происходит на каждом шаге и совпадает ли итог с ожиданием. Если сведений о сохранении или внешнем обмене нет, не нужно добавлять их по догадке.

**Проверьте себя.** Программа показала 5. Можно ли по одному этому факту утверждать, что 5 записано в файл или базу «Полки»?

**Ответ:** нет. Показ не является подтверждением такого сохранения. В рассматриваемом фрагменте действия с файлом, базой и сетью вообще не заданы.

## 9. Проверим понимание

**Вопрос 1.** Что должно выдать `print(3 + 4)` и в каком порядке происходят вычисление и показ?

**Вопрос 2.** Для примера из части 6 мы остановились после первой строки. Число 8 уже входит в текущий вывод?

**Вопрос 3.** Что изменится, если поменять местами две строки примера из части 6?

**Вопрос 4.** Допустимая запись показывает 5, затем 8. Доказывает ли это, что она соответствует любой поставленной задаче?

### Ответы и объяснения

1. **Число 7 на одной строке.** Сначала выражение `3 + 4` даёт значение 7, затем `print` выдаёт его для показа. Исходная строка целиком не печатается. Повторите части 2–3.
2. **Нет, пока показано только 5.** Число 8 будет выдано второй строкой; будущий результат не включают в текущее состояние. Повторите части 5–6.
3. **Сначала покажется 8, затем 5.** Сами независимые вычисления сохраняют значения, но порядок вывода меняется. Повторите часть 7.
4. **Нет.** Результат нужно сравнить с конкретным ожиданием. Возможно, требовался другой порядок, другие числа или другое действие; допустимость записи этого не решает. Повторите часть 8 и урок 5.5.

## 10. Практика без запуска: заполните таблицу

**Цель:** проследить три вычисления и отдельно зафиксировать вывод после каждой строки.

### Условие

Рассматриваем отдельное выполнение с начала. Исходный вывод пуст. Используется Python; `+` означает сложение чисел, `*` — умножение; `print` выдаёт значение выражения внутри скобок на новой строке.

```python
print(3 + 1)
print(2 * 3)
print(1 + 1)
```

Внешних вводов, скрытых действий, сети и сохранения нет. Все нужные элементы уже объяснены в частях 2–6. Ничего устанавливать или запускать не нужно.

### Задание

1. Для каждой строки укажите действие и вычисленное значение.
2. Запишите весь вывод после первой, второй и третьей строки.
3. Отдельно рассмотрите новый вариант: поменяйте местами первую и третью строки, среднюю оставьте на месте. Начните разбор заново с пустым выводом.
4. Объясните, изменились ли значения отдельных выражений и что изменилось в полном выводе.

### Образец результата

Исходный вариант:

| После строки | Действие | Значение | Весь вывод к этому моменту |
|---|---|---|---|
| Первой | Сложить 3 и 1 | 4 | 4 |
| Второй | Умножить 2 на 3 | 6 | Сначала 4, затем 6 |
| Третьей | Сложить 1 и 1 | 2 | Сначала 4, затем 6, затем 2 |

Полный ожидаемый вывод:

```text
4
6
2
```

Вариант с перестановкой:

```python
print(1 + 1)
print(2 * 3)
print(3 + 1)
```

| После строки | Действие | Значение | Весь вывод к этому моменту |
|---|---|---|---|
| Первой | Сложить 1 и 1 | 2 | 2 |
| Второй | Умножить 2 на 3 | 6 | Сначала 2, затем 6 |
| Третьей | Сложить 3 и 1 | 4 | Сначала 2, затем 6, затем 4 |

Его полный ожидаемый вывод:

```text
2
6
4
```

Значения выражений не изменились: 3 + 1 по-прежнему даёт 4, 2 * 3 даёт 6, 1 + 1 даёт 2. Изменился порядок их вычисления и показа. Второй вариант не продолжает вывод первого.

### Самопроверка

- В каждом варианте три вычисления и три строки вывода.
- Исходный вариант даёт 4, затем 6, затем 2.
- Вариант с перестановкой даёт 2, затем 6, затем 4.
- После первой строки в текущем выводе только одно число; будущие значения не добавлены.
- Перестановка не превратила сложение в умножение и не изменила числа внутри выражений.
- Второй вариант начинается с пустого вывода, а не добавляется к первому.
- Показанные числа не объявлены сохранёнными в файле или базе.

Если трудно, вернитесь к таблице в части 5. Сначала вычислите значение одной строки, затем добавьте только его к прежнему выводу. После этого переходите к следующей строке.

## 11. Что стоит запомнить и куда идём дальше

Прослеживание помогает получить ожидаемый результат по правилам, а не по догадке. Выражение даёт значение, а `print` в наших примерах выдаёт его для показа. Если строк несколько, нужно учитывать и их действия, и порядок вывода.

В выбранной точке есть только результаты уже пройденных шагов. Предсказание будущего не делает его состоявшимся. Ручной разбор также не доказывает фактический запуск или сохранение данных.

В следующем уроке введём переменные: как обращаться к текущему рабочему значению по имени и менять его между инструкциями. Затем разберём, почему число и похожий на него текст могут вести себя по-разному.

## Словарь урока

- **Прослеживание выполнения** — разбор по правилам очередных инструкций, полученных значений и изменений состояния.
- **Состояние на шаге** — существенные для задачи данные в выбранный момент.
- **Выражение** — запись, по которой получается значение.
- **Вывод** — данные или сообщения, которые программа выдаёт при работе.
- **`print`** — встроенное средство Python для выдачи данных; в примерах урока показывает одно переданное значение на новой строке.
- **Синтаксис**, напоминание — правила допустимого построения записи на языке.
