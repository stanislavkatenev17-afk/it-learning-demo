# Исходники учебной платформы

Запуск — в корневом README.md, приёмка — в CONTRIBUTING.md. Команды выполняются из корня как `node site/имя.mjs`; из папки site доступны прежние `node build.mjs`, `node serve.mjs`. package.json содержит эквивалентные npm-скрипты. Установка пакетов не нужна.

## Слои интерфейса

Порядок CSS задаёт src/index.html: workspace → color-themes → lesson-visuals → learning-ui → module-1…6-visuals → course-visuals → module-7-visuals. Общие изменения могут затронуть разные модули: проверяйте несколько типов уроков.

- workspace.css — базовая геометрия и компоненты; color-themes.css — светлая палитра.
- learning-ui.css/.js — дополнительные компоненты оболочки.
- module-1-visuals.css включает общие современные компоненты схем; следующие модульные слои добавляют локальные правила.
- course-visuals.css и modern-visual-kit.mjs — компоненты последующих модулей; module-7-visuals.css — дополнительный слой 7.5.
- src/app.js — маршруты и учебное состояние; src/startup.js — проверка запуска и понятный отказ.

Большинство иллюстраций — собственные HTML/CSS/SVG-схемы в module-*-visuals.mjs. lesson-visuals.mjs подключает генераторы; build.mjs применяет их к преобразованным Markdown.

## Ресурсы

В assets включены только шесть используемых WebP: монитор, горы, дом, процессор, RAM и SSD. Рядом — SOURCES.json с происхождением и запросами генератору. Указанные там оригинальные PNG сохранены локально владельцем и в минимальный комплект не входят; для сборки они не нужны.

Это сгенерированные нейтральные учебные рендеры, не фотографии определённых моделей и мест. Условные окна не выдаются за интерфейсы конкретных программ. При изменении компоновки сохраняйте смысловые оговорки и текстовые представления схем.

Подробные правила — ILLUSTRATION_GUIDE.md. Его ссылки на исторические галереи/отчёты относятся к локальным материалам владельца, которые не включены в репозиторий.

## Выдача

build.mjs читает 64 Markdown, программу и банк заданий, создаёт data.js и SVG-фоны, копирует активные исходники и ресурсы. Итог — 25 файлов в dist. build-output.mjs сохраняет прежнюю выдачу в build-archive и заменяет dist только готовой сборкой.

dist, build-archive и временные папки исключены из Git. update-demo.mjs работает в копии этого репозитория с корневыми index.html и .nojekyll; публичный снимок обновляет владелец после приёмки.
