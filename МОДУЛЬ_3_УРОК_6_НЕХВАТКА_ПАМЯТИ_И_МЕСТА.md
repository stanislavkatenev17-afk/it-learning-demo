# Чем отличаются нехватка оперативной памяти и нехватка места на накопителе

## 1. Что означает «закончилась память»

Представьте две ситуации.

В первой вы хотите сохранить новый документ. Программа сообщает, что для записи файла недостаточно места на накопителе.

Во второй вы открываете большую фотографию в программе просмотра. Программа сообщает, что для этого действия недостаточно оперативной памяти.

В разговоре обе ситуации иногда описывают одинаково: «закончилась память». Но в сообщениях названы разные части компьютера и разные ограничения.

В этом уроке вы научитесь различать эти ограничения, объяснять смысл подходящих действий и замечать случаи, когда информации для вывода недостаточно.

Все сообщения в уроке — учебные формулировки. В конкретной программе надписи могут выглядеть иначе. Мы рассматриваем смысл сообщений, а не расположение кнопок.

## 2. Коротко вспомним две задачи

**Накопитель** хранит файлы, в том числе после выключения компьютера. Сохранённые документы и фотографии занимают на нём место.

**Оперативная память** используется программами во время работы. В ней размещаются инструкции и данные, с которыми программы работают сейчас.

Обе части имеют ограниченную вместимость, но выполняют разные задачи.

| Что сравниваем | Накопитель | Оперативная память |
|---|---|---|
| Для чего используется | Для хранения файлов | Для работы программ |
| Что может оказаться ограничено | Место для записи данных | Память, которую можно предоставить для работы |
| Что означает нехватка в нашем примере | Для нового файла не хватает места | Для открытия фотографии программе не хватает оперативной памяти |

Слово **«достаточно» всегда связано с определённой задачей**. Свободное место на накопителе может ещё быть, но его может не хватать для конкретного файла. Программе может хватать оперативной памяти для простого действия, но не хватать для более требовательного.

Нехватка не обязательно означает, что устройство сломалось. Иногда исправному компьютеру просто не хватает доступной вместимости для выбранной задачи.

## 3. Когда не хватает места на накопителе

Вернёмся к документу. Вы написали новый список покупок и хотите впервые сохранить его в файл.

Текст уже виден в окне программы: с ним можно работать. Но для сохранения нужно записать данные на накопитель. Если для этой записи недостаточно места, сохранение может не выполниться.

Получается важная ситуация: **документ открыт, но нужного сохранённого файла ещё нет**. Видимость текста на экране не заменяет успешного сохранения — это мы разобрали в предыдущем уроке.

Недостаток места может также помешать записать ещё одну фотографию или создать отдельную копию документа. В каждом таком случае речь идёт о хранении данных.

Если сообщение прямо говорит о нехватке места для записи файла, закрытие окна другой программы само по себе не уберёт с накопителя сохранённые фотографии и документы. Они продолжают занимать место.

**Проверьте себя.** Новый файл не удалось сохранить из-за недостатка места. Какое ограничение названо и что известно о сохранении текста, который остаётся виден в программе?

**Ответ:** Назван недостаток места на накопителе. Описанная запись не удалась; видимый текст нельзя считать успешно записанным этим действием. При затруднении вернитесь к уроку 5 об открытии и сохранении.

## 4. Когда не хватает оперативной памяти

Теперь другая ситуация. Вы работаете с текстом и одновременно открываете несколько фотографий в другой программе.

Каждой работающей программе нужна оперативная память. Данные разных программ могут находиться в ней одновременно. Одна программа тоже может использовать разное количество памяти для разных действий.

Предположим, при открытии ещё одной фотографии появилось сообщение: «Для этого действия недостаточно оперативной памяти». В этом случае ограничение относится к работе программы с данными.

На накопителе при этом может оставаться много места для файлов. **Свободное место для хранения не доказывает, что программе хватает оперативной памяти.**

Если закрыть ненужную программу, часть использовавшейся ею оперативной памяти обычно становится доступна для другой работы. Но этого не обязательно хватит для выбранного действия: сама задача тоже может требовать много памяти.

Недостаток оперативной памяти может сопровождаться замедлением работы или отказом выполнить действие. Однако обратный вывод неверен: любое замедление ещё не доказывает нехватку памяти.

**Проверьте себя.** На накопителе достаточно места для новых фотографий. Можно ли только по этому факту утверждать, что программе хватит оперативной памяти для работы с любым изображением?

**Ответ:** нет. Вы знаете о месте для хранения, а вопрос касается памяти для работы. Если эти величины смешиваются, ещё раз сравните две задачи в таблице части 2.

## 5. Почему действия помогают по-разному

Сопоставим действия с тем, на что они направлены.

| Действие | Что оно означает |
|---|---|
| Закрыть ненужную работающую программу | Обычно позволяет использовать часть занятой ею оперативной памяти для другой работы |
| Окончательно удалить ненужный обычный файл с накопителя | Обычно освобождает занятое им место для хранения; к перемещению в корзину вернёмся ниже |
| Закрыть документ, который уже сохранён | Завершает работу с ним в окне, но оставляет сохранённый файл на накопителе |
| Перенести файл в другую папку того же накопителя без изменения содержимого | Меняет расположение файла, но не убирает с накопителя его данные |

Представьте, что вы закрыли программу просмотра фотографий. Программа перестала работать с открытыми изображениями, и часть оперативной памяти может стать доступна. Но сами сохранённые фотографии остались на накопителе.

Теперь представьте, что вы убрали лишнюю сохранённую копию фотографии. Это относится к месту для хранения файлов. Такое действие не увеличивает установленный объём оперативной памяти — вместимость этой части компьютера.

Здесь мы различаем назначение действий. Компьютер сложнее этой учебной схемы: программа при закрытии может дополнительно записывать или удалять свои файлы. Но из одного факта закрытия нельзя сделать вывод, что место для нужного сохранения обязательно освободилось.

**Проверьте себя.** Видео переместили из «Загрузок» в «Видео» на том же накопителе. Содержимое не менялось. Что изменилось: расположение, количество данных файла или свободное место из-за этой смены папки?

**Ответ:** Изменилось расположение. Данные остались на том же накопителе и не уменьшились; одна смена папки не освобождает занятое ими место. Если трудно, различите порядок в папках и освобождение места.

## 6. Что важно знать о сохранении и удалении

Перед закрытием программы нужно сохранить нужные изменения. Если сохранение не удалось, закрытие не превращает рабочий текст в сохранённый файл. Оставьте документ открытым, пока выясняете, как сохранить нужный текст.

При удалении тоже есть важная подробность. Во многих системах файл сначала попадает в **корзину** — специальное место для удалённых файлов, из которого их ещё можно вернуть. Пока обычный файл находится в корзине, его данные обычно продолжают занимать место на накопителе.

Поэтому исчезновение файла из исходной папки ещё не означает, что место освободилось. В этом уроке под окончательным удалением понимается удаление файла из корзины либо удаление, при котором он в неё не попадает. После этого занятое им место обычно становится доступным для записи других данных.

Задания ниже выполняются на описанных ситуациях. Удалять личные файлы, закрывать важную работу или менять настройки для них не требуется.

## 7. Почему «компьютер работает медленно» недостаточно

Сравните три сообщения:

1. «Для записи нового файла недостаточно свободного места на накопителе».
2. «Для работы программы недостаточно оперативной памяти».
3. «Компьютер работает медленно».

В первых двух сообщениях прямо названо ограничение. В третьем описано только наблюдение. Оно не говорит, какая именно часть компьютера ограничивает работу и связана ли причина с памятью или накопителем вообще.

Полезно уточнить:

- Какое действие не получается: сохранить файл, открыть изображение или выполнить что-то другое?
- Есть ли сообщение программы и что в нём написано?
- Названы ли в нём оперативная память, накопитель или свободное место?

Если этих сведений нет, ответ **«пока недостаточно информации»** будет точнее уверенного предположения.

Даже сам факт, что оперативная память используется программами, не означает проблему. Она для этого и предназначена. Не нужно делать вывод о нехватке только по слову «занято» без связи с конкретной задачей и дополнительными сведениями.

**Небольшое действие:** придумайте один уточняющий вопрос человеку, который говорит: «У меня закончилась память».

**Подходящий ответ:** «Что вы пытались сделать и какое сообщение появилось?» Он помогает получить факты вместо догадки.

## 8. Как рассуждать в подобных ситуациях

Можно опираться на четыре шага.

1. **Назовите действие.** Например: сохранить новый документ или открыть фотографию.
2. **Прочитайте сообщение целиком, если оно есть.** Слово «память» без уточнения может быть неоднозначным.
3. **Свяжите сообщение с задачей части компьютера.** Хранение файлов относится к накопителю; данные для текущей работы программ — к оперативной памяти.
4. **Проверьте вывод.** Что известно точно? Какой информации ещё не хватает? Почему выбранное действие относится к этому ограничению?

Эти шаги помогают понять ситуацию, но не заменяют полную проверку причины неисправности. По одной жалобе не нужно сразу решать, какие детали покупать или какие файлы удалять.

## 9. Проверка понимания

Сначала ответьте самостоятельно, затем прочитайте объяснения. В ответах своими словами важен смысл, а не дословное совпадение с образцом.

**Вопрос 1.** Программа сообщает: «Для записи нового файла недостаточно свободного места на накопителе». Какое ограничение названо?

А. Недостаточно места для хранения данных.  
Б. Обязательно сломался процессор.  
В. Обязательно не хватает оперативной памяти.

**Вопрос 2.** Программа сообщает, что для действия не хватает оперативной памяти. Вы окончательно удалили ненужный файл, который не был открыт ни в одной программе. Увеличили ли вы этим установленный объём оперативной памяти? Объясните ответ.

**Вопрос 3.** Вы закрыли программу просмотра фотографий. Можно ли по одному этому факту утверждать, что сохранённые фотографии удалились с накопителя и теперь есть место для нового файла?

**Вопрос 4.** Человек говорит: «Окна стали открываться медленнее». Достаточно ли этих сведений, чтобы выбрать между нехваткой оперативной памяти и нехваткой места на накопителе? Назовите один полезный уточняющий вопрос.

**Вопрос 5.** Обычный файл переместили в корзину. Он исчез из исходной папки. Доказывает ли это, что занятое им место уже освободилось?

### Ответы и объяснения

1. **А. Недостаточно места для хранения данных.** Сообщение прямо называет накопитель и запись файла. Из него не следует, что сломался процессор или что проблема относится к оперативной памяти. При ошибке повторите части 2–3.
2. **Нет.** Вы изменили количество хранящихся файлов, а не вместимость оперативной памяти. Это разные части компьютера. Даже если такое действие помогло какой-то другой операции, из этого не следует увеличение установленной памяти. Повторите части 4–5.
3. **Нет.** Закрытие программы обычно освобождает часть используемой оперативной памяти, а сохранённые фотографии продолжают храниться. Факт закрытия не доказывает наличие места для нового файла. Повторите часть 5.
4. **Недостаточно.** Подходящий вопрос: «Есть ли сообщение программы и что в нём написано?» Можно также спросить, какое действие выполнялось и в какой программе. Важно не приписывать причину одному общему наблюдению. Повторите части 7–8.
5. **Нет.** Файл в корзине обычно продолжает занимать место на накопителе. Исчезновение из папки и освобождение места — разные события. Повторите часть 6.

Если возникла ошибка, вернитесь к указанному объяснению и попробуйте ответить снова. Результат проверки не закрывает доступ к следующим материалам курса.

## 10. Практика без компьютера: объясните ситуацию

**Цель:** различить ограничения и связать действие с задачей соответствующей части компьютера.

На бумаге или мысленно составьте таблицу с четырьмя столбцами: «Ситуация», «Что известно», «Как это связано с памятью или накопителем», «Объяснение».

Разберите четыре случая:

**А.** Новая копия документа не записалась. Сообщение прямо говорит о недостатке свободного места на накопителе. Человек предлагает просто закрыть сохранённый документ в окне.

**Б.** При открытии изображения программа сообщает о нехватке оперативной памяти. Рядом работает другая программа, которая сейчас не нужна. Изменения в ней сохранены. Человек предлагает закрыть её, а затем повторить действие.

**В.** Сохранённое видео переместили между папками одного накопителя. Данные файла не изменились. Человек ожидает, что для других файлов стало больше места.

**Г.** Человек сообщает только: «Компьютер стал медленным». Сообщений программ и описания конкретного действия нет.

Для каждого случая объясните, насколько вывод обоснован. Если сведений мало, укажите, что нужно уточнить. Заполните свою таблицу до чтения образца.

### Образец результата

| Ситуация | Что известно | Связь с памятью или накопителем | Объяснение |
|---|---|---|---|
| А | Не хватает места для записи новой копии | Накопитель | Закрытие сохранённого документа не удаляет его файл. Оно само по себе не решает указанное ограничение |
| Б | Программа прямо сообщает о нехватке оперативной памяти | Оперативная память | Закрытие ненужной программы обычно делает часть памяти доступной. Это разумная попытка уменьшить текущую потребность, но успех не гарантирован |
| В | Файл остался на том же накопителе | Место для хранения не освободилось из-за одной смены папки | Изменилось расположение, а не количество данных файла |
| Г | Есть только общее наблюдение | Определить причину пока нельзя | Нужно уточнить действие и наличие сообщения; выбирать причину по догадке рано |

**Самопроверка:** вы справились, если можете:

- В случаях А и Б назвать разные ограничения и объяснить их связь с хранением или работой программы.
- В случае В отделить порядок в папках от освобождения места.
- В случае Г признать недостаток информации и задать подходящий уточняющий вопрос.
- Объяснить, почему закрытие программы в случае Б может помочь, но не доказывает, что памяти после этого хватит.

Если перепутали А и Б, вернитесь к частям 3–5. Если ошиблись в В, проследите, на каком накопителе остались данные. Если выбрали причину для Г без уточнений, повторите часть 7.

## 11. Объясните своими словами

Представьте, что знакомый спрашивает: «На накопителе ещё есть место. Почему программа жалуется на память?»

Ответьте двумя-тремя предложениями без технических подробностей.

**Образец ответа:** «Накопитель хранит файлы, а оперативная память нужна программам во время работы. Свободное место для файлов не показывает, сколько оперативной памяти доступно для этого действия. Сначала стоит прочитать сообщение и уточнить, о какой памяти речь».

Формулировка может быть другой. Проверьте, что в вашем объяснении есть две разные задачи и нет обещания определить любую причину по одному признаку.

## 12. Что стоит запомнить

| Если речь идёт о… | В первую очередь различаем… |
|---|---|
| Месте для записи файлов | Вместимость накопителя и уже хранящиеся данные |
| Памяти для работы программ | Оперативную память и текущую работу программ |
| Общем замедлении без других сведений | Наблюдение и пока не установленную причину |

Закрыть программу, удалить файл и переместить файл — разные действия. Чтобы понять их смысл, нужно спросить, что именно изменится: работа программы, количество хранящихся данных или расположение файла.

В модуле 4 разберём, как компьютер представляет данные и как измеряется их объём. После объяснения единиц сможем вернуться к числовым характеристикам оперативной памяти и накопителя. Для этого урока достаточно понимать разницу их задач.

## Словарь урока

| Понятие | Значение |
|---|---|
| Свободное место на накопителе | Место, которое ещё можно использовать для записи данных |
| Доступная оперативная память | Память, которую компьютер может предоставить для работы программ |
| Установленный объём оперативной памяти | Вместимость установленной в компьютере оперативной памяти; закрытие программы само по себе её не увеличивает |
| Корзина | Специальное место для удалённых файлов, из которого их ещё можно вернуть; такие файлы обычно продолжают занимать место |
| Наблюдение | То, что удалось заметить, например медленное открытие окна |
| Причина | То, из-за чего возникло наблюдаемое поведение; её нужно устанавливать по сведениям, а не только предполагать |
