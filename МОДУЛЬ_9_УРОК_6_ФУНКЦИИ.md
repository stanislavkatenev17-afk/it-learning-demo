## 1. Как использовать одно действие в разных местах

Представьте, что к нескольким числам нужно прибавить по одному. Для 2 получится 3, для 5 — 6. Правило одно, входные значения разные.

Можно повторять запись вычисления в каждом месте программы. Другой способ — описать действие один раз, дать ему имя и обращаться к нему с нужными данными.

**Функция — именованная часть программы, задающая действие; она может принимать входные значения и возвращать результат.** Здесь начнём с простой именованной функции, которая получает целое число и возвращает число на единицу больше.

Функция помогает использовать один способ вычисления в разных местах. Это отличается от цикла: цикл задаёт повторение по правилу, а функция — действие, к которому можно обратиться. Позже объединим их в одном примере.

Знакомое средство `print` теперь тоже можно назвать функцией — встроенной функцией Python для выдачи данных. До этого мы разбирали её конкретное действие; сейчас познакомимся с устройством собственного именованного действия.

После урока вы сможете различить описание функции и её вызов, проследить переданные значения и отделить возвращённый результат от показа. Установка и запуск Python не требуются.

**Проверьте себя.** Чтобы прибавлять один в разных местах программы, обязательно каждый раз заново копировать всё описание вычисления?

**Ответ:** нет. Можно определить функцию и затем вызывать её с нужным входным значением. Сам вызов и передачу данных разберём далее.

## 2. Что входит в определение функции

**Определение функции описывает её имя, параметры и тело. Тело функции — инструкции, задающие её действие.**

**Параметр — имя, через которое внутри функции используют переданное значение.** Для числа выберем имя `number`, которое означает «число». Это выбранное автором имя, как `count` в предыдущих уроках.

Для определения в Python используется слово `def`. После него пишется имя функции. Выберем `add_one` — «прибавить один». Знак `_` называется нижним подчёркиванием; здесь он соединяет части имени, а не задаёт арифметическое действие.

После имени стоят круглые скобки с параметром, затем знакомое двоеточие. Инструкции тела располагаются ниже с отступом четыре пробела.

Начало определения:

```python
def add_one(number):
```

Это пока неполный фрагмент: дальше должно быть тело. Разобранная строка сообщает имя действия и имя для его входного значения, но ещё не показывает само вычисление.

Когда программа выполняет определение, она создаёт функцию и связывает её с именем. **Вызов — обращение, которое запускает описанное действие с конкретными входными значениями.** Одно определение ещё не является таким вызовом: тело не выполняется для какого-то числа само по себе.

**Проверьте себя.** Если описать функцию «прибавить один», она сразу покажет 3, хотя конкретного вызова и показа ещё нет?

**Ответ:** нет. Определение подготавливает действие, но не вызывает тело для числа 2 и не добавляет показ результата.

## 3. Как вернуть вычисленное значение

Внутри нашей функции нужно прибавить 1 к числу и передать результат обратно туда, откуда к ней обратятся.

Слово Python `return` означает возврат из текущего вызова. Здесь сначала вычисляется записанное после него выражение, затем значение возвращается в место вызова и этот вызов завершается.

**Возвращённое значение — результат, который вызов передаёт для дальнейшего использования в программе.** Оно не обязано показываться человеку.

Теперь можно собрать полное определение:

```python
def add_one(number):
    return number + 1
```

| Часть | Назначение |
|---|---|
| `def` | Начать определение функции |
| `add_one` | Имя описанного действия |
| `(number)` | Параметр, через который используется переданное число |
| `:` | Начать тело |
| Четыре пробела перед `return` | Показать принадлежность инструкции телу |
| `return number + 1` | Вычислить новое число, вернуть его и завершить вызов |

Здесь нет `print`. Возврат не является скрытым показом и не записывает значение в файл или базу.

Мы рассматриваем функции, которые явно возвращают целое число. Это ограничение примеров, а не требование ко всем функциям Python. У других функций могут быть иные действия и виды результатов.

**Проверьте себя.** Сопоставьте возврат из функции и показ через `print`: куда направлен результат каждого действия в наших примерах?

**Ответ:** Возвращённое значение передаётся для дальнейшего использования в программе. `print` выдаёт значение для показа. Возврат не добавляет показ автоматически.

## 4. Как передать конкретное число

**Аргумент — конкретное значение, передаваемое при вызове.** Параметр — имя в определении, аргумент — значение для одного обращения.

После определения `add_one` вызов записывается как `add_one(2)`. Имя указывает, какое действие выполнить; скобки после него обозначают вызов, а число внутри — переданный аргумент.

Действия для этого вызова:

```text
Аргумент: 2
     ↓
Параметр number в текущем вызове получает значение 2
     ↓
Вычислить number + 1: получилось 3
     ↓
Вернуть 3 в место вызова и завершить вызов
```

Мы не показываем 3 автоматически. Пока лишь объяснили, какое значение получается у вызова и что оно может быть использовано следующими действиями.

Если обратиться к той же функции с аргументом 5, параметр в этом вызове получит 5 и будет возвращено 6. Имя параметра не означает навсегда закреплённое число 2.

Подробности того, где доступны разные имена программы, сейчас не нужны. Для разбора достаточно помнить: параметр используется внутри конкретного вызова с переданным для него значением.

**Проверьте себя.** Параметр `number` всегда обозначает 2, если первый разобранный вызов был `add_one(2)`?

**Ответ:** нет. При следующем вызове он получает значение нового аргумента. Для `add_one(5)` это 5, а возвращённое значение равно 6.

## 5. Как использовать результат и отдельно показать его

Выберем имя `result` — «результат». В строке `result = add_one(2)` справа находится вызов. По знакомому правилу присваивания сначала получается правая часть, затем её значение связывается с именем слева.

Разберём полный фрагмент с начала:

```python
def add_one(number):
    return number + 1

result = add_one(2)
print(result)
```

Пустая строка отделяет определение от последующих действий и сама не задаёт показ. Строки присваивания и `print` идут без отступа, поэтому находятся вне тела функции.

| Этап | Что произошло | Текущее `result` | Весь вывод |
|---|---|---|---|
| Определение | Создана функция, связанная с именем `add_one` | Ещё не задано | Пусто |
| Вызов и присваивание | Для аргумента 2 возвращено 3 | 3 | Пусто |
| Показ | Прочитано и показано `result` | 3 | 3 |

Внутри функции было вычисление и возврат. Снаружи — присваивание и показ. Их не нужно объединять в одно неразличимое действие.

Знакомая `print` тоже вызывается со значением. В нашем фрагменте она выдаёт это значение для показа. Она не подменяет `return` нашей вычисляющей функции и не используется здесь для получения числовой суммы.

**Проверьте себя.** Выполнена строка `result = add_one(2)`, а следующая строка с `print` ещё не выполнялась. Укажите `result` и вывод в этот момент.

**Ответ:** `result` обозначает 3, а вывод ещё пуст. Число возвращено и присвоено; только следующая строка задаст показ. Если добавили 3 в вывод, разделите эти события.

## 6. Что произойдёт при втором вызове

Добавим к предыдущему фрагменту новое обращение с другим числом. Полный пример:

```python
def add_one(number):
    return number + 1

result = add_one(2)
print(result)
result = add_one(5)
print(result)
```

Определение выполнено один раз, а описанная функция вызвана дважды. При первом вызове аргумент 2 даёт возврат 3. При втором аргумент 5 даёт возврат 6.

Второе присваивание связывает `result` с 6. Оно не прибавляет новое число к прежнему 3: такого сложения в строке нет.

| Этап | Аргумент | Возврат | Текущее `result` | Весь вывод |
|---|---|---|---|---|
| Первый вызов и присваивание | 2 | 3 | 3 | Пусто |
| Первый показ | — | — | 3 | 3 |
| Второй вызов и присваивание | 5 | 6 | 6 | 3 |
| Второй показ | — | — | 6 | Сначала 3, затем 6 |

Полный ожидаемый вывод:

```text
3
6
```

Черта в колонке означает, что на этом этапе не происходит нового вызова `add_one`. Сам `print` при показе, конечно, вызывается; в таблице отдельно прослеживается именно наша вычисляющая функция.

**Проверьте себя.** Раньше `result` обозначало 3. Второй вызов вернул 6, и это значение присвоили тому же имени. Назовите новое значение и объясните, почему здесь не получается 9.

**Ответ:** Новое значение — 6. Присваивание связывает имя с возвращённым значением; сложение прежнего 3 с новым 6 не задано. При затруднении найдите действие в строке.

## 7. Как соединить функцию, повторение и выбор

К концу модуля можно соединить уже знакомые действия. Для каждого элемента списка вызвать «прибавить один», получить число, проверить его и показать один из вариантов.

Определение функции расположим до цикла. Внутри цикла будем вызывать её для текущего элемента. Переписывать определение на каждом проходе не нужно.

Новая для чтения деталь — **вложение**: одна группа инструкций находится внутри другой. Выбор `if`/`else` будет частью тела цикла, поэтому выполняется заново на каждом проходе.

Разберём уровни до итогового задания:

| Начальные пробелы | Что на этом уровне |
|---|---|
| Нет | Начало цикла и общий показ после него |
| Четыре | Инструкции тела цикла, в том числе начало `if` и `else` |
| Восемь | Инструкция внутри выбранной ветви, которая сама находится в цикле |

У определения функции собственное тело тоже начинается с четырёх пробелов. Одинаковое число пробелов в разных местах не связывает все строки во всём файле: важно, к какой конструкции относится группа и где она заканчивается.

Имя `value` в итоговой практике означает «полученное значение». Оно получает результат вызова на текущем проходе. Сравнение будет использовать именно его, а не прежний элемент до прибавления одного.

**Проверьте себя.** Если функция вызывается внутри цикла, её определение обязательно нужно заново копировать для каждого элемента?

**Ответ:** нет. В нашем примере она определена до цикла. На каждом проходе вызывается уже описанное действие с очередным аргументом.

## 8. Чего не означает возврат из функции

В уроке 8.5 API описывал возможности и правила программного взаимодействия. Сейчас вызов `add_one` вычисляет число внутри одной программы. Сети, запросов и базы в нём нет.

Один запрос к приложению может приводить к множеству внутренних вызовов функций. И наоборот, функция может работать совсем без запросов к другим программам. Поэтому запрос API и функция — разные понятия.

```text
Наш пример: число → локальный вызов → возвращённое число

Запись в сервисе: отдельные действия с данными и хранилищем;
получение подтверждения зависит от заданного взаимодействия.
```

Возврат 3 не означает, что 3 сохранено на накопителе или подтверждено сервером «Полки». Как и раньше, нужно смотреть, какие действия действительно заданы.

Даже имя функции само по себе не доказывает её последствия. Если действие названо понятным словом, всё равно важно прочитать описание и инструкции. В нашей `add_one` только арифметика и возврат; скрытых сохранений нет.

**Проверьте себя.** Функция вернула число. Следует ли из этого, что сервер «Полки» подтвердил запись этого числа?

**Ответ:** нет. В примере нет ни обращения к серверу, ни записи. Возврат из текущего вызова не заменяет такое взаимодействие.

## 10. Практика А без запуска: два вызова

**Цель:** отдельно проследить аргументы, возвраты, присваивания и вывод.

### Условие

Новое независимое выполнение с начала; весь нужный код дан ниже. Скрытых действий, внешних вводов и сохранений нет.

```python
def add_one(number):
    return number + 1

result = add_one(1)
print(result)
result = add_one(4)
print(result)
```

### Задание

Для каждого вызова `add_one` укажите аргумент, значение параметра и возврат. После каждого присваивания и показа запишите текущее `result` и весь вывод. Объясните, что произойдёт при определении.

### Образец результата

При определении создаётся функция, тело не вызывается, вывод пуст.

| Этап | Аргумент и значение параметра | Возврат `add_one` | `result` после этапа | Весь вывод |
|---|---|---|---|---|
| Первый вызов и присваивание | 1 | 2 | 2 | Пусто |
| Первый показ | Нового вызова `add_one` нет | — | 2 | 2 |
| Второй вызов и присваивание | 4 | 5 | 5 | 2 |
| Второй показ | Нового вызова `add_one` нет | — | 5 | Сначала 2, затем 5 |

Полный ожидаемый вывод:

```text
2
5
```

### Самопроверка

- Определение не названо первым вызовом тела.
- Аргументы — 1 и 4, возвраты — 2 и 5.
- Присваивания сами не добавляют вывод.
- После второго присваивания `result` равно 5, прежнее 2 не прибавляется.
- Каждый отдельный `print` показывает текущее значение.

Если трудно, повторите части 4–6: сначала проследите один вызов, затем присваивание и только потом показ.

## 11. Практика Б без запуска: свяжите шесть тем

**Цель:** объяснить небольшой код целиком и предсказать результат по шагам.

### Условие

Это другое независимое выполнение. Список содержит целые 1 и 3 по порядку. Все элементы записи уже объяснены, включая уровни отступов в части 7. `value` — имя для полученного значения. Сообщения «Мало» и «Конец» — обычные тексты.

```python
def add_one(number):
    return number + 1

for item in [1, 3]:
    value = add_one(item)
    if value >= 3:
        print(value)
    else:
        print("Мало")
print("Конец")
```

Перед разбором проверьте структуру. Определение функции идёт отдельно до цикла. В теле цикла четыре пробела перед присваиванием и перед `if`/`else`. Внутри их ветвей восемь пробелов перед показом. Последний `print` без отступа стоит после всего цикла.

Список не меняется, ошибок, сети и скрытых действий нет. Ничего запускать не нужно.

### Задание

1. Опишите алгоритм обычными словами. Найдите определение функции, тело цикла, ветви и последний показ.
2. Разберите первый проход. Запишите одну строку таблицы: `item` → аргумент → возврат и `value` → результат сравнения → ветвь → добавленный вывод.
3. По той же схеме разберите второй проход. Затем добавьте действие после цикла, запишите весь вывод и подсчитайте вызовы `add_one` и `print`.
4. Начните отдельную таблицу для независимого варианта со списком `[]`. Остальной код не меняйте. Укажите, что покажется и получит ли `value` значение. Результаты первого варианта сюда не переносятся.

### Образец результата

Сначала описать действие «прибавить один». Для каждого элемента списка вызвать его, присвоить результат имени `value`, проверить, не меньше ли он трёх. Если да — показать число, иначе — показать «Мало». После обхода показать «Конец».

| Проход | `item` и аргумент | Возврат и `value` | `value >= 3` | Ветвь | Добавленный вывод |
|---|---|---|---|---|---|
| Первый | 1 | 2 | `False` | `else` | Мало |
| Второй | 3 | 4 | `True` | `if` | 4 |

После первого прохода `value` равно 2, после второго — 4. Функция сама ничего не показывает: её возврат используется в присваивании, затем в сравнении. Вывод задаётся выбранной ветвью.

После цикла общий показ добавляет последнюю строку. Полный ожидаемый вывод:

```text
Мало
4
Конец
```

`add_one` вызывается два раза, `print` — три раза. Одно определение `add_one` не считается ещё одним вызовом её тела.

При пустом списке проходов и вызовов `add_one` нет. Определение функции по-прежнему выполнено, но тело не вызвано. Срабатывает только общий `print`, вывод:

```text
Конец
```

В этом новом выполнении `value` не получило значения. Его нигде не читают, потому что всё тело цикла пропущено. Нельзя переносить 4 из первого варианта в независимый пустой вариант.

### Самопроверка

- При первом проходе сравнивается полученное 2, при втором — полученное 4.
- На каждом проходе выбрана одна ветвь.
- Вывод идёт в порядке «Мало», 4, «Конец».
- Возвраты функции не добавлены в вывод как отдельные показы.
- Последнее сообщение показано один раз после цикла.
- Для пустого списка нет ни прохода, ни вызова `add_one`.
- Пустой вариант не получил прежнее `value` из другого выполнения.

Если трудно, разделите задачу: вызов по практике А, текущий элемент по 9.5, выбор по 9.4. Соедините эти шаги для одного прохода, затем повторите для следующего и добавьте общий показ.

## Словарь урока

- **Функция** — в рассматриваемых примерах именованная часть программы, задающая действие; может принимать входные значения и возвращать результат.
- **Определение функции** — описание её имени, параметров и тела.
- **Тело функции** — инструкции её действия.
- **Вызов** — обращение, запускающее описанное действие с конкретными входными значениями.
- **Параметр** — имя для использования переданного значения внутри функции.
- **Аргумент** — конкретное значение, передаваемое при вызове.
- **Возвращённое значение** — результат, переданный из вызова для дальнейшего использования.
- **Вложение** — расположение одной группы инструкций внутри другой, например выбора внутри цикла.
