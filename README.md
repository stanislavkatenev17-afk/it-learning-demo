# Введение в IT — демонстрационная версия

Платформа для людей без технической подготовки: 11 модулей, 64 урока, схемы, задания, поиск и словарь.

Для просмотра работающего сайта используйте адрес GitHub Pages, указанный в Website/About этого репозитория после размещения. Просмотр файла index.html на github.com не запускает платформу.

Попробуйте урок 1.2, демонстрацию 7.5 и проверку модуля 1. Тексты и задания пока черновики; прогресс сбрасывается при обновлении страницы. Входа, постоянного хранения и видео нет.

Нужна обратная связь о понятности объяснений, удобстве пользования и соответствии программы аудитории. Это текущая наработка, не окончательно утверждённый продукт.
