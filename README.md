# Введение в IT — исходники и работающая демоверсия

**[Открыть платформу](https://stanislavkatenev17-afk.github.io/it-learning-demo/)** — без регистрации и установки программ.

Курс для людей без технической подготовки: 11 модулей, 64 урока, 191 иллюстрация, задания, поиск и словарь. Материалы — черновики. Прогресс сбрасывается при обновлении страницы; входа, постоянного хранения и видео пока нет.

В репозиторий добавлены действующие исходники для совместной доработки. Прежняя демоверсия сохранена. Вариант дизайна и серверные функции рассматриваются отдельными PR.

## Быстрый запуск

Нужен **Node.js 24**; проверено на 24.22.1. npm и установка пакетов не требуются: сборщик и сервер используют стандартные модули Node.js. Другие версии в этом комплекте не проверены.

Скачайте Code → Download ZIP и распакуйте либо клонируйте:

```sh
git clone https://github.com/stanislavkatenev17-afk/it-learning-demo.git
cd it-learning-demo
```

Из корня распакованной/клонированной папки выполните:

```sh
node site/build.mjs
node site/serve.mjs
```

Откройте **http://127.0.0.1:4173/**. Терминал с сервером остаётся занят; остановка — Ctrl+C. Если порт занят, остановите прежний экземпляр либо задайте PORT для этого процесса.

После изменения исходников повторите `node site/build.mjs` в другом терминале и обновите страницу. Автоматической пересборки сейчас нет. Обновление сбрасывает временные учебные отметки.

## Проверки

После сборки, из корня репозитория:

```sh
node site/verify.mjs
node site/verify-terms.mjs
node site/verify-theme.mjs
```

Проверяются состав/порядок курса, сохранность текста и ссылок, структура заданий, выделение терминов и светлое оформление. Удобочитаемость и пользовательские сценарии проверяйте в браузере по CONTRIBUTING.md.

## Исходники и опубликованный снимок

`site/dist` создаётся локально и исключён из Git. Корневые `index.html`, CSS/JS и `assets` — отдельный снимок GitHub Pages; исходники в site не подменяют эти файлы автоматически.

После приёмки владелец обновляет снимок командой `node site/update-demo.mjs` после сборки и проверок, проверяет diff и включает результат в согласованный коммит. Порядок — в CONTRIBUTING.md.

В текущей сборке нет внешних пакетов, CDN или удалённых API. Архивы прежнего дизайна, служебный аудит и исходный сторонний Word не включены. `.gitattributes` сохраняет байты без автоматической замены переводов строк, чтобы сборка воспроизводилась одинаково.
