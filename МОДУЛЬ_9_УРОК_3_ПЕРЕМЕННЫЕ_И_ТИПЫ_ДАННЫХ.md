## 1. Как обратиться к текущему значению

В прошлом уроке числа были записаны прямо в выражениях: сложить 2 и 3, показать результат. Но программе часто нужно использовать одно рабочее значение в нескольких следующих действиях, а затем заменить его новым.

Представьте, что программа учитывает количество карточек. Сначала их две, потом появилась ещё одна. Программе нужно обратиться сначала к прежнему количеству, а после изменения — к новому.

Для этого используют имена. **Значение — конкретные данные**, например число 2 или текст о встрече. **Переменная — имя, с которым в программе связано текущее значение.**

В примерах урока выберем имя `count`. Оно записано латинскими буквами и означает «количество». Это имя придумал автор примера, а не встроенная команда Python. По нему будем обращаться к текущему количеству.

```text
Имя: count → связанное с ним значение: 2
```

Имя и значение различаются. В дальнейшем с тем же именем можно связать 3. Само написание `count` при этом не изменится.

После урока вы сможете проследить такие изменения и объяснить, почему число 2 и текст «2» могут вести себя по-разному. Устанавливать и запускать программы не нужно: все действия разбираем по записи.

**Проверьте себя.** Если с именем `count` связано число 2, являются ли слово count и число 2 одним и тем же?

**Ответ:** нет. `count` — имя, а 2 — его текущее значение. По имени программа может обратиться к этому значению.

## 2. Как связать имя со значением

**Присваивание — действие, связывающее имя с полученным значением.** В нашей записи Python для него используется одиночный знак `=`.

Имя пишется слева, то, откуда получается значение, — справа. Сначала вычисляется правая часть, затем полученное значение связывается с именем слева.

Теперь разберём целую строку:

```python
count = 2
```

| Элемент | Значение в этой строке |
|---|---|
| `count` | Имя для текущего количества |
| `=` | Присвоить полученное справа значение имени слева |
| `2` | Значение, с которым связывается имя |
| Пробелы вокруг `=` | Помогают читать запись |

Справа стоит одно число, поэтому дополнительных вычислений здесь нет. После строки `count` обозначает 2.

Показа пока не было. Как мы договорились в 9.2, рассматриваем исходный текст без автоматического показа значений интерактивной средой. Чтобы явно выдать данные, нужна инструкция с `print`.

```text
До присваивания: значение для count в этом примере ещё не задано
После присваивания: count → 2
Вывод: пусто
```

Знак `=` здесь задаёт действие, а не просьбу показать равенство на экране. Проверку равенства разберём в следующем уроке отдельно.

**Проверьте себя.** В новом выполнении есть только строка `count = 2`. Укажите текущее значение имени и весь вывод.

**Ответ:** С именем `count` связано число 2. Вывод пуст: присваивание не задаёт показ. Если записали 2 в вывод, найдите, была ли инструкция `print`.

## 3. Имя без кавычек и текст в кавычках

Чтобы показать текущее значение, можно передать в `print` имя. В этом месте имя означает: используйте связанное с ним значение.

```python
count = 2
print(count)
```

Круглые скобки и действие `print` знакомы из 9.2. Сначала задаётся значение для `count`, затем оно читается по имени и выдаётся для показа. Ожидаемый вывод:

```text
2
```

Теперь введём способ записать текст. **Строка — текстовая последовательность символов.** В наших примерах прямые двойные кавычки `"` обозначают начало и конец такого текста. Сами кавычки не входят в показываемое содержание.

После объяснения кавычек можно сравнить независимый вариант:

```python
count = 2
print("count")
```

Здесь внутри скобок не обращение к имени, а текст из пяти букв. Ожидаемый вывод:

```text
count
```

| Запись внутри `print` | Что используется |
|---|---|
| `count` | Текущее значение по имени |
| `"count"` | Сам текст count |

Кавычки меняют смысл записи. Не нужно искать значение имени, если в примере задан текст в кавычках. И наоборот: нельзя читать имя без кавычек как просьбу показать его написание.

Перед обращением к имени значение должно быть задано. В обоих примерах это сделано первой строкой. Без неё в новом независимом выполнении у `count` не было бы значения для чтения.

**Проверьте себя.** Одинаков ли смысл `print(count)` и `print("count")`, если `count` обозначает 2?

**Ответ:** нет. В первом случае показывается 2, во втором — текст count. Во втором случае кавычки задают сами символы, а не обращение к текущему значению.

## 4. Как изменить значение и не перепутать шаги

Вернёмся к количеству карточек. Сначала их две, затем добавилась одна. В программе нужно получить новое число и связать его с прежним именем.

В строке `count = count + 1` справа сначала читается текущее значение `count`, к нему прибавляется 1, затем результат присваивается имени слева.

Разберём отдельный пример с начала:

```python
count = 2
print(count)
count = count + 1
print(count)
```

После первой строки `count` обозначает 2. Вторая показывает 2. На третьей происходят действия:

```text
Прочитать прежнее значение count: 2
                 ↓
Вычислить 2 + 1: получилось 3
                 ↓
Связать имя count с новым значением: 3
```

Четвёртая строка читает уже новое значение и показывает 3.

| После строки | Значение `count` | Весь вывод к этому моменту |
|---|---|---|
| Первой | 2 | Пусто |
| Второй | 2 | 2 |
| Третьей | 3 | 2 |
| Четвёртой | 3 | Сначала 2, затем 3 |

Ожидаемый вывод целиком:

```text
2
3
```

Третья строка не исправляет уже показанную первую строку вывода. Она меняет текущее значение, а следующий `print` добавляет новый показ.

Здесь нет утверждения «два равно трём». Мы задаём действие присваивания. Поэтому нужно сначала получить правую часть из прежнего значения, а потом обновить значение имени.

**Проверьте себя.** Перед строкой `count = count + 1` имя `count` обозначает 2. Назовите прежнее значение, значение правой части и новое значение имени.

**Ответ:** Прежнее значение — 2; правая часть даёт 3; после присваивания имя обозначает 3. Это последовательность вычисления и обновления, а не математическое равенство 2 = 3.

## 5. Почему видимого написания недостаточно

Сравним число 2 и строку `"2"`. Во втором случае внутри кавычек находится один символ — цифра 2. Это текстовое значение.

**Тип данных определяет, что это за значение и какие операции с ним предусмотрены.** Пока познакомимся с двумя типами:

| Вид значения | Пример записи | Название типа в Python |
|---|---|---|
| Целое число — число без дробной части | `2` | `int` |
| Строка — последовательность текстовых символов | `"2"` | `str` |

Слова `int` и `str` здесь — названия типов для узнавания. Мы пока не используем их как команды и не выполняем преобразования.

Если по отдельности показать число 2 и текст «2», видимое содержание будет похоже. Но это не доказывает, что данные одного типа. Различие проявится в действиях над ними.

В Python тип относится к значению, с которым связано имя. То же имя можно позже связать со значением другого типа. Это правило Python, а не обязательное устройство всех языков.

В основных расчётах этого урока `count` всё время обозначает целое число. Мы не будем менять его на текст посреди вычисления: сначала научимся уверенно прослеживать более простой случай.

Связь «имя → значение» помогает понимать программу. Но это не буквальная схема физической ячейки памяти с навсегда закреплённым адресом. Подробности внутреннего размещения сейчас не нужны.

**Проверьте себя.** Если два показанных значения выглядят как 2, доказывает ли один внешний вид, что у них одинаковый тип?

**Ответ:** нет. В одном случае это может быть целое число, в другом — текст из одного символа. Для чтения примера нужно учитывать исходную запись и правила действий.

## 6. Почему один знак даёт разные действия

Для двух целых чисел `+` означает сложение. Для двух строк тот же знак задаёт соединение текстов в указанном порядке.

Сначала рассмотрим два независимых выражения:

| Выражение | Что задано | Результат |
|---|---|---|
| `2 + 3` | Сложить два целых числа | Число 5 |
| `"2" + "3"` | Соединить два текста | Строка «23» |

Во втором случае символ 3 добавляется после символа 2. Получается текст из двух символов, а не числовая сумма.

Можно явно показать оба результата:

```python
print(2 + 3)
print("2" + "3")
```

Ожидаемый вывод:

```text
5
23
```

Последняя строка показывает текст «23». Кавычки определяли текст в исходной записи, но сами в вывод не входят.

Теперь отдельный вопрос, который не продолжает этот фрагмент: что означает `2 + "3"`? Слева целое число, справа строка. В рассматриваемом Python такое сложение приводит к ошибке. Автоматический перевод текста в число здесь не задан и не происходит.

Поэтому нельзя обещать ни числовую сумму 5, ни текст «23» для этого смешанного выражения. Чтобы получить определённый результат, понадобились бы другие явно описанные действия. Их сейчас не вводим.

**Проверьте себя.** Для выражения `2 + "3"` определите виды двух значений и объясните, почему здесь не получится просто пообещать числовую сумму 5.

**Ответ:** Слева целое число, справа строка. Правила этой операции не складывают их как два числа; понимание человеком символа «3» не добавляет преобразования в число. При затруднении сначала определите типы.

## 7. Данные для ответа «истина или ложь»

Есть ещё один вид значений, который пригодится в следующем уроке.

**Логическое значение — одно из двух значений: «истина» или «ложь».** В Python они записываются как `True` и `False`, с заглавной первой буквой и без кавычек. Название этого типа — `bool`.

Пока знакомимся с самими значениями. В следующем уроке получим их при проверке правила и используем для выбора действия.

| Запись | Что это |
|---|---|
| `True` | Логическое значение «истина» |
| `False` | Логическое значение «ложь» |
| `"False"` | Строка из символов F, a, l, s, e |

Слово в кавычках не становится логической ложью только потому, что человек читает его как английское false. Кавычки задают текст, как в предыдущих примерах.

`True` и `False` — специальные значения Python, а не придуманные автором имена вроде `count`. Их написание нужно соблюдать.

Мы пока не проверяем истинность произвольного текста и не выполняем арифметику с логическими значениями. Для ближайшего шага достаточно различать типы и два логических результата.

**Проверьте себя.** `False` и `"False"` — одно и то же значение?

**Ответ:** нет. Первое — логическое значение, второе — строка. Сходство написания не отменяет кавычки и правила типа.

## 8. Переменная и сохранённые данные

Рабочее значение переменной используется при текущем выполнении программы. Как мы разбирали в модуле 3, данные в работе и данные, сохранённые для последующего открытия, нужно различать.

Присваивание `count = 2` само по себе не записывает файл на накопитель. Изменение `count` также не означает, что автоматически обновилось какое-то поле в базе «Полки».

В уроке 8.4 **поле базы** было отдельной частью данных записи, например названием заметки. Переменная программы — имя для текущего значения в работе. Программа может получить значение из базы и работать с ним, но эти роли не становятся одним понятием.

Чтобы изменение попало в базу, программа должна выполнить соответствующие действия с хранилищем. Если участвуют разные программы, потребуются их взаимодействие и условия, которые мы уже различали в модуле 8. В примерах этого урока их нет.

```text
Присвоить рабочее значение → использовать его в текущем вычислении

Записать файл или обновить базу → отдельные действия,
которые в примерах не заданы
```

Это не означает, что переменные обязательно «живут отдельно от всего компьютера». Выполнение по-прежнему связано с памятью, процессором и ОС. Мы лишь не приписываем одной инструкции последствия, которых она здесь не задаёт.

**Проверьте себя.** `count` стало равно 3. Можно ли из этого заключить, что соответствующая запись «Полки» уже обновлена?

**Ответ:** нет. Изменилось рабочее значение в нашем примере. Действия с базой не заданы, подтверждения записи также нет.

4. **Нет.** В Python тип относится к текущему значению; имя может быть связано с другим значением. Поле базы — отдельное понятие хранения, и присваивание не означает его обновление. Повторите части 5 и 8.

## 10. Практика по описанию: значение, тип и вывод

**Цель:** проследить изменение имени и отдельно определить вид данных и показанный результат.

### Условие

Начинаем отдельное выполнение с начала, исходный вывод пуст. Используются уже объяснённые правила Python.

```python
count = 3
count = count + 2
print(count)
print("3" + "2")
```

Скрытых вводов, сохранений, обращений к базе и других изменений нет. Запускать фрагмент не нужно.

### Задание

1. Для каждой строки запишите действие, текущее значение `count` и весь вывод после неё.
2. Отдельно классифицируйте три значения: `3`, `"3"`, `True`.
3. Рассмотрите независимое выражение `3 + "2"`. Можно ли обещать числовую сумму 5? Этот вопрос не добавляет пятую строку к программе.

### Образец результата

| После строки | Действие | Текущее `count` | Весь вывод |
|---|---|---|---|
| Первой | Связать имя с числом 3 | 3 | Пусто |
| Второй | Вычислить 3 + 2 и присвоить 5 | 5 | Пусто |
| Третьей | Показать текущее значение | 5 | 5 |
| Четвёртой | Соединить тексты «3» и «2», показать | 5 | Сначала 5, затем текст «32» |

Полный ожидаемый вывод:

```text
5
32
```

В отдельной классификации: `3` — целое число, `"3"` — строка, `True` — логическое значение.

Независимое выражение `3 + "2"` приводит к ошибке: целое число не складывается со строкой по этим правилам. Оно не входит в четыре строки программы и не меняет уже составленную таблицу.

### Самопроверка

- После двух присваиваний `count` последовательно обозначает 3 и 5.
- До первого `print` вывод пуст.
- Показано 5, затем текст «32», каждое на новой строке.
- Четвёртая строка не меняет `count`.
- Число, строка и логическое значение различены.
- Ошибочное смешанное выражение не добавлено к программе.
- Изменение имени и показ не названы сохранением.

Если трудно, повторите части 2–4 и подпишите правую часть каждого присваивания. Для типов вернитесь к частям 5–7: сначала определите вид каждого значения, затем действие над ним.

## 11. Что стоит запомнить и куда идём дальше

Переменная позволяет обращаться к текущему значению по имени. При присваивании сначала получается правая часть, затем имя связывается с результатом. Само это действие ничего не показывает и не обещает сохранение.

Тип влияет на смысл операций. Два целых числа через `+` складываются, два текста соединяются; смешивание числа со строкой не добавляет скрытого преобразования. Логические значения `True` и `False` нужно отличать от похожих текстов в кавычках.

В следующем уроке получим логический результат сравнением. Затем по этому результату выберем одно из двух действий.

## Словарь урока

- **Значение** — конкретные данные, с которыми работает программа.
- **Переменная** — имя, с которым в программе связано текущее значение.
- **Присваивание** — действие, связывающее имя с полученным значением.
- **Тип данных** — характеристика значения, определяющая его вид и предусмотренные операции.
- **Целое число** — число без дробной части; в Python тип `int`.
- **Строка** — текстовая последовательность символов; в Python тип `str`.
- **Логическое значение** — истина или ложь; в Python `True` и `False`, тип `bool`.

## Редакторские заметки и основания

Восемь коротких проверок, четыре итоговых вопроса и одна практика соответствуют карточке. Переменная и присваивание определены до применения; кавычки и строка — до сравнения имени с текстом. В части 4 отдельное выполнение с начальным 2 даёт вывод 2/3; в практике новое выполнение с начальным 3 даёт 5/«32». Фрагменты не продолжают друг друга без объявления. Смешанные ошибочные выражения вынесены за основные программы.

Правила проверены по [Python Tutorial: Numbers](https://docs.python.org/3/tutorial/introduction.html#numbers), [Text](https://docs.python.org/3/tutorial/introduction.html#text) и [Python: Boolean Type](https://docs.python.org/3/library/stdtypes.html#boolean-type-bool). Связь имени и значения не выдаётся за фиксированную физическую ячейку; правила Python не обобщаются на все языки. Типы `int`, `str`, `bool` даны как названия, преобразования и вызовы этих средств не используются. Особенности арифметики с `bool` не входят в урок.

Ответы сверены вручную; Python не найден среди доступных команд среды, локального исполнения не было. Не изучаются адреса памяти, изменяемость объектов, дробные вычисления, преобразования и обработка исключений. Ветка выбора ещё не используется: переход к 9.4 подготовлен через логические значения. Проверки на учениках и видео не было.
