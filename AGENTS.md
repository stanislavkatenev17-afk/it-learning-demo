# Работа с исходниками платформы

- Сначала прочитайте README.md и CONTRIBUTING.md. Команды выполняются из корня репозитория.
- Исходники интерфейса — site/src; учебные тексты — корневые МОДУЛЬ_*_УРОК_*.md; схемы — site/module-*-visuals.mjs и общие преобразователи.
- Корневые index.html, CSS/JS и assets — опубликованный снимок GitHub Pages. Редактируйте исходники; не ограничивайте исправление сгенерированными файлами.
- Сборка: node site/build.mjs. Проверки: node site/verify.mjs, node site/verify-terms.mjs, node site/verify-theme.mjs.
- Не меняйте учебные объяснения, задания, ответы и смысл схем незаметно в PR только по дизайну. Содержательные изменения отмечайте отдельно для приёмки.
- Сохраняйте клавиатурное управление, видимый фокус, узкую компоновку, предупреждение о временном прогрессе и действие/сброс демонстрации 7.5. Текущая тема светлая; новый вариант оформления рассматривается через PR.
- Тексты курса обращаются к ученику на «вы». Неназванные интерфейсы обозначаются как условные; цвет не должен быть единственным носителем смысла.
- Архивы, локальные отчёты, зависимости и временные файлы сборки не включайте в Git.
- Обновление публичного снимка и изменение состава функций требуют решения владельца; порядок — в CONTRIBUTING.md.
